# Obsidian AI 第二大脑插件

这是一个面向 Obsidian 的 AI 插件项目，目标是把本地 Markdown 知识库扩展成一个可对话、可检索、可创作、可整理、可分析的「会思考的第二大脑」。

当前版本已经具备侧边栏对话、授权范围、本地检索、安全编辑、知识库分析、可编辑图谱生成、现有 Excalidraw 画布文本编辑与 HTML 互动预览。

## 当前能力

1. 多服务商侧边栏对话，支持会话切换、归档与恢复。
2. 可控文件访问范围、本地检索与引用溯源。
3. 选中文本后的右键 AI 操作，以及笔记修改的差异预览、确认应用和撤销。
4. 知识库健康分析、MOC 和回顾草稿。
5. 将笔记或 AI 回复生成 Excalidraw / Mermaid 可编辑图谱。
6. 通过对话向已有 Excalidraw 画布的指定位置添加文字，或修改现有文字。
7. 直接预览库内 `.html` / `.htm` 文件，运行页面里的交互功能。

会话和消息不再按数量自动截断。侧边栏先显示最近 60 条消息，可点击“加载更早的消息”；归档会隐藏普通列表中的会话并保留内容。失败或停止的回复会保存状态和已有内容，不作为完整回答加入后续模型历史。完整保存记录不代表每次请求都会向模型发送全部历史。

## 可编辑图谱

安装并启用 Obsidian Excalidraw 插件后，可以从命令面板、编辑器右键二级菜单或 AI 回复操作栏生成思维导图、流程图、时间线、概念关系图、系统架构图和决策树。创建前可查看实际布局并在本地调整节点、关系、标题和方向；未检测到 Excalidraw 时会自动创建 Mermaid 笔记。

## 编辑已有 Excalidraw 画布

先安装并启用 Obsidian Excalidraw 插件，再从以下任一入口打开文本编辑弹窗：

- 在对话中输入 `/draw 在“项目计划”标题下方添加三条待办`。
- 点击对话输入框旁的“编辑 Excalidraw 画布”按钮。
- 运行命令 `AI: Edit Excalidraw drawing`，或右键绘图文件选择“AI 编辑画布内容”。

在弹窗中选择目标画布，输入指令，点击“预览修改”。预览列出将新增或修改的文字、坐标和字号；可先编辑预览文字，再点击“应用修改”。支持 `.excalidraw`、`.excalidraw.md` 及带 Excalidraw 标记的绘图笔记。

例如可要求“在 x=200、y=300 添加‘本周目标’”“将选中的文字改为‘已完成’”，或以现有元素的上、下、左、右及内部位置为参照。当前对话范围只有一个绘图文件时，明确的修改指令也会直接进入此流程；使用 `/draw` 可以明确指定进入画布编辑。对话中的近期完整回答可供指令引用，例如“把上面的总结放到标题下面”。

已完成的 AI 回复还提供“写入 Excalidraw 画布”操作，可把回复作为文本带入弹窗。选择“直接在坐标处插入文本”，填写 x、y 后预览，无需请求模型。

本功能通过 ExcalidrawAutomate API 添加或更新文本，不提供任意图形重构。预览后画布发生变化时会拒绝应用，要求重新预览；应用后可在 Excalidraw 中撤销。现有绘图编辑必须安装 Excalidraw，不会降级为 Mermaid。通用批量笔记修改计划会排除绘图文件，避免直接覆盖其内部格式。

## 预览 HTML 互动页面

打开库内 `.html` / `.htm` 文件即可进入预览；也可运行 `AI: Preview HTML file` 选择文件，或在文件右键菜单中选择“预览 HTML 页面”。如果其他插件已接管 HTML 的默认打开方式，仍可使用命令或右键入口。

预览支持内联 CSS、JavaScript，以及通过相对路径引用的库内 CSS、JS、图片等资源。页面和已加载依赖发生修改时会自动刷新，也可点击“刷新”；“源码”标签显示只读的原始 HTML。

可在对话中要求“生成一个包含内联 CSS 和 JavaScript 的 HTML 番茄钟”。当完整回复包含 `html` 代码块或完整 HTML 文档时，点击回复下方的“保存 HTML 并预览”，会在 `AI Second Brain/HTML/` 创建页面并打开。

HTML 在隔离的 iframe 中运行，默认阻止在线资源；确实需要访问外部资源时，可在当前页面勾选“允许在线资源”。切换文件或关闭后重新打开时，该选项恢复关闭；工具栏“刷新”保留当前选择。此预览适合自包含交互页面，不提供服务器运行环境，也不保证支持 JavaScript 模块的相对 `import`、需要同源存储或登录状态的应用。授权在线资源后，页面脚本可以向外部服务发送请求，应根据页面内容决定是否开启。

## 构建与验证

在项目根目录运行：

```sh
npm install
npm test
npm run build
```

构建产物为 `main.js`。将它与 `manifest.json`、`styles.css` 一起放入库的 `.obsidian/plugins/ai-second-brain/` 后，在 Obsidian 中启用插件。浏览器交互回归和真实 Obsidian 手验步骤见[加载与验收清单](docs/testing.md)。浏览器测试使用模拟的 Obsidian API，不能替代真实 Obsidian 与 Excalidraw 插件的集成验收。

## 核心原则

- 用户必须明确知道 AI 能读取哪些笔记。
- 所有文件读取先在本地完成，只有授权内容可发送给 AI。
- AI 生成或修改笔记时，应尽量可预览、可追溯、可撤销。
- UI 应贴近 Obsidian 原生体验，克制、清晰、轻量。
