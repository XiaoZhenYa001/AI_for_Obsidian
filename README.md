# Obsidian AI 第二大脑插件

这是一个面向 Obsidian 的 AI 插件项目，目标是把本地 Markdown 知识库扩展成一个可对话、可检索、可创作、可整理、可分析的「会思考的第二大脑」。

当前版本已经具备侧边栏对话、授权范围、本地检索、安全编辑、知识库分析、可编辑图谱生成、现有 Excalidraw 画布文本编辑与 HTML 互动预览。

## 当前能力

1. 多服务商侧边栏对话，支持会话切换、归档与恢复。
2. 可控文件访问范围、本地检索与引用溯源。
3. 选中文本后的右键 AI 操作，以及笔记修改的差异预览、确认应用和撤销。
4. 知识库健康分析、MOC 和回顾草稿。
5. 将笔记或 AI 回复生成 Excalidraw / Mermaid 可编辑图谱。
6. 通过对话向已有 Excalidraw 画布的指定位置添加文字，或修改现有文字。
7. 直接预览与编辑库内 `.html` / `.htm` 文件，保存源码并运行页面里的交互功能。

会话和消息不再按数量自动截断。侧边栏先显示最近 60 条消息，可点击“加载更早的消息”；归档会隐藏普通列表中的会话并保留内容。失败或停止的回复会保存状态和已有内容，不作为完整回答加入后续模型历史。完整保存记录不代表每次请求都会向模型发送全部历史。

## 可编辑图谱

安装并启用 Obsidian Excalidraw 插件后，可以从命令面板、编辑器右键二级菜单或 AI 回复操作栏生成思维导图、流程图、时间线、概念关系图、系统架构图和决策树。创建前可查看实际布局并在本地调整节点、关系、标题和方向；未检测到 Excalidraw 时会自动创建 Mermaid 笔记。

## 编辑已有 Excalidraw 画布

先安装并启用 Obsidian Excalidraw 插件，再从以下任一入口进入聊天内画布编辑：

- 在对话中输入 `/draw 在“项目计划”标题下方添加三条待办`。
- 点击对话输入框旁的“编辑 Excalidraw 画布”按钮。
- 运行命令 `AI: Edit Excalidraw drawing`，或右键绘图文件选择“AI 编辑画布内容”。

默认使用当前或对话绑定的画布，没有目标时才弹出文件选择器。聊天输入框上方显示目标名称，点击可切换；点击“退出画布编辑”返回普通对话。支持 `.excalidraw`、`.excalidraw.md` 及带 Excalidraw 标记的绘图笔记。

直接在聊天中发送修改指令。生成结果在消息里展示新增文本，或修改前后的文字，只保留“写入画布”和“放弃”。不满意可继续说“再简短一点”，AI 会调整尚未写入的完整方案，旧预览随即失效。确认后一次写入；生成和预览期间不改动画布，也不锁定绘图或源码，可以继续编辑、平移和缩放。停止、失败或放弃不会留下中间写入。

例如可要求“在 x=200、y=300 添加‘本周目标’”“将选中的文字改为‘已完成’”，或以现有元素的上、下、左、右及内部位置为参照。当前对话范围只有一个绘图文件时，明确的修改指令也会直接进入此流程；使用 `/draw` 可以明确指定进入画布编辑。对话中的近期完整回答可供指令引用，例如“把上面的总结放到标题下面”。

已完成的 AI 回复提供“插入 Excalidraw 画布”操作，直接插入已看过的回复，无需再次请求模型或填写坐标。有选中元素时放在选区下方，没有选区时放在当前视野中心。写入完成后可点击消息里的“撤销本次写入”，也可使用 Excalidraw 原生撤销。

目标在生成时固定，切换当前文件不会把结果写入另一个画布。预览后目标画布发生变化、关闭或移动时会拒绝写入，需要重新生成；写入后有其他画布修改时，聊天撤销会拒绝覆盖，请使用画布原生撤销。关闭或切换聊天后，未写入的预览失效，重新打开只能查看记录，需要重新生成方案。

本功能通过 ExcalidrawAutomate API 添加或更新文本，不提供任意图形重构。现有绘图编辑必须安装 Excalidraw，不会降级为 Mermaid。通用批量笔记修改计划会排除绘图文件，避免直接覆盖其内部格式。

## 预览 HTML 互动页面

在插件设置的“HTML 预览”中打开“启用 HTML 原生预览”（默认关闭），重新加载插件后，打开库内 `.html` / `.htm` 文件即可进入预览。也可运行 `AI: Preview HTML file`，或在文件右键菜单选择“预览 HTML 页面”。关闭设置会立即关闭本插件的预览页；更改文件默认打开方式需要重新加载插件。如果其他插件已接管 HTML，仍可使用显式命令或右键入口。

默认“完整预览”直接交给浏览器渲染原始 HTML，不删除 `base`、`iframe`、`srcset` 等标签或属性。支持 CSS、JavaScript、相对 ES Module 导入、JSON fetch、表单交互、媒体和嵌入页面。HTML 所在文件夹作为资源根目录，请将页面依赖放在该文件夹及子目录中；不提供目录列表或笔记、隐藏配置文件访问。页面和已加载依赖发生修改时会自动刷新，也可点击“刷新”。

点击“源码”即可编辑，点击“保存”或按 `Ctrl/Cmd+S` 写入原文件，再切回“预览”查看效果。未保存的内容不会执行；正常关闭或切换文件时会在本机保留草稿，重新打开可恢复。草稿不作为笔记同步，突然退出可能丢失最后约 600ms 的输入。本机草稿存储失败时，正常关闭会尝试在原文件旁写入 `-recovery-…html` 恢复副本并提示；若写盘也失败，会打开源码复制窗口。外部修改与草稿冲突时会拒绝覆盖，可“另存副本”，或确认“放弃修改”后重新载入。源码使用轻量文本编辑器，暂不提供语法高亮和代码补全。

默认勾选“隐藏时暂停”：切换到源码、隐藏标签页或最小化窗口时销毁页面运行环境，停止该页面的脚本；返回可见预览时重新加载，页面中未持久化的计数、表单等状态会重置。需要番茄钟、音频等持续运行时，可取消勾选。此选项只影响当前预览页。

工具栏保留“隔离预览”，用于只需内联或打包资源的简单页面；该模式会限制嵌入内容和模块相对导入。完整预览中的本地存储仅在当前预览会话中使用，关闭再打开会获得新的独立环境。

可在对话中要求“生成一个包含内联 CSS 和 JavaScript 的 HTML 番茄钟”。当完整回复包含 `html` 代码块或完整 HTML 文档时，点击回复下方的“保存 HTML 并预览”，会在 `AI Second Brain/HTML/` 创建页面并打开。

HTML 在独立来源的 iframe 中运行，默认阻止在线资源；使用 CDN、远程图片或接口时，在当前页面勾选“允许在线资源”。切换文件或关闭后重新打开时，该选项恢复关闭；工具栏“刷新”保留当前选择。完整预览不提供业务后端，不绕过浏览器跨域规则或远程网站的嵌入限制，不开放宿主 Node API、Service Worker 和顶层页面跳转。它保留原始页面内容，但不能替代任意网站的完整运行环境。

## 构建与验证

性能优化覆盖常用路径：流式输出使用轻量文本更新，完成后统一渲染 Markdown 与图表；并发检索共用索引任务，热索引不重复读取文件；指定文件范围直接查找所选文件；知识库分析最多同时读取 8 个文件，分批让出主线程，补链候选只保留前 50 条；只保存聊天内容时不重建服务商或重复刷新上下文控件。没有为这些优化添加常驻轮询。

源码编辑、冲突处理和预览暂停已在浏览器 6 倍 CPU 降速下回归。该测试模拟较慢 CPU，不能替代真实 Obsidian、省电模式和电池功耗测量；实际能耗还取决于 HTML 自身脚本、其他插件、库规模和模型服务。

在项目根目录运行：

```sh
npm install
npm test
npm run build
```

构建产物为 `main.js`。将它与 `manifest.json`、`styles.css` 一起放入库的 `.obsidian/plugins/ai-second-brain/` 后，在 Obsidian 中启用插件。浏览器交互回归和真实 Obsidian 手验步骤见[加载与验收清单](docs/testing.md)。浏览器测试使用模拟的 Obsidian API，不能替代真实 Obsidian 与 Excalidraw 插件的集成验收。

## 核心原则

- 用户必须明确知道 AI 能读取哪些笔记。
- 所有文件读取先在本地完成，只有授权内容可发送给 AI。
- AI 生成或修改笔记时，应尽量可预览、可追溯、可撤销。
- UI 应贴近 Obsidian 原生体验，克制、清晰、轻量。
