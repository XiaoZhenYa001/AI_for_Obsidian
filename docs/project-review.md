# 项目审查与体验优化

日期：2026-10-09。目标：简约、功能完善、各功能协调。以现有功能为范围，检查界面入口、会话与上下文状态、请求生命周期、结果保存和撤销。

## 现有功能评估

| 功能 | 当前可完成的任务 | 实现边界 |
| --- | --- | --- |
| 聊天与会话 | 多服务商问答、流式输出、停止、切换、归档、完整记录保存 | 模型请求只使用有限历史；输入草稿在本次插件运行期间保留 |
| 上下文与检索 | 跟随、锁定或手动选文件；保存范围切换；本地文本检索、来源定位 | 属于文本检索，尚无向量语义检索；确认全部文件不等于每篇全文都会发送 |
| 选区操作与内容生成 | 解释、总结、改写等任务；生成后预览、插入或创建笔记 | 写入依赖原文和目标校验；模型输出质量仍需用户审阅 |
| 批量修改 | 按项预览创建、更新、移动、删除；冲突校验、回滚与撤销 | 排除绘图文件；仅保留最近批次的撤销记录，未恢复冲突须先处理 |
| 知识库健康、MOC、回顾 | 孤立笔记、摘要和 Front Matter 检查，标题重复、标签与补链候选，生成导航和回顾草稿 | 是本地结构检查；重复和补链是候选，不能证明语义冲突、真假或知识完整性 |
| 图谱生成 | 生成规格、布局预览、本地调整、保存 Excalidraw 或 Mermaid | 现有 Excalidraw 编辑支持文字添加和修改，尚不支持任意图形重构 |
| HTML 页面 | 从回答保存 HTML、预览交互、编辑源码、保留草稿和处理外部冲突 | 默认关闭；不提供业务后端；浏览器跨域和页面自身依赖限制仍适用 |

## 本次已修复的问题

| 问题 | 优化后的行为 |
| --- | --- |
| 完整上下文选择误用 8 个锁定文件的限制 | 所选文件完整保存和重载；仅固定锁定文件限制为 8 个 |
| 全部取消上下文后，每次提问重新弹出确认 | 空选择也能复用，范围变化或主动重选时再次确认 |
| 开始新对话仍保留旧画布目标和未写入预览 | 先使旧预览失效并保存，再进入普通新对话 |
| 关闭侧栏后输入草稿无法恢复 | 草稿保存在插件实例中，切换和重新打开侧栏都能恢复 |
| 健康分析将绘图源码当成笔记 | 文件夹分析、健康报告和 MOC 排除 Excalidraw；健康分析只处理 Markdown |
| 链接元数据更新后复用过时健康报告 | 元数据事件使缓存失效；过时的并发任务不能重新发布旧缓存 |
| 关闭内容生成、修改计划窗口仍继续请求和更新预览 | 关闭即取消；晚到结果不再渲染；读取期间取消后不会继续调用模型 |
| 生成过程中按钮和状态各自维护 | 输入区共享忙碌状态，空白不可发送，发送与停止切换一致 |
| 健康报告部分统计无详情，长列表截断 | 补充 Front Matter 详情；笔记、重复组和补链结果可逐批展开 |
| 带标点的范围名称可能破坏 MOC 或回顾的 YAML | 范围名称写为带引号的 YAML 字符串 |

## 界面与功能衔接

- 顶部用会话标题替代固定产品标题，保留新对话和工具菜单；上下文与聊天模型常驻第二行。
- 普通回复常驻复制、保存为笔记、更多操作；插入、替换、图谱、画布和修改计划集中到菜单。
- 保存笔记自动保留回答引用；HTML 内容始终有保存预览入口，未启用时可进入设置。
- 工具菜单连接内容生成、图谱、健康检查、MOC 和批量笔记修改撤销。
- 范围菜单提供已保存范围、授权文件检查和重新选择参考文件。
- 设置概览保留三项关键状态，文件预览默认折叠；模板、图谱和 HTML 分类按需展开。
- 清空聊天前确认；创建新对话直接开始，后续可修改职责和范围。

## 验证与实际使用

自动回归覆盖真实功能模块及模拟的 Obsidian、Excalidraw 和模型接口。执行命令、浏览器回归和真实宿主验收见 [testing.md](testing.md)。

本轮验证结果：112 项自动测试通过，TypeScript 检查与生产构建通过；聊天工作流、画布编辑、输入框、HTML 基础交互、HTML 安全、完整 HTML 预览、HTML 源码编辑共 7 组浏览器回归通过。源码编辑回归包含 6 倍 CPU 降速场景；聊天与设置布局已人工查看测试截图。

模型网络连接、真实 Obsidian 的设置入口、原生主题、Excalidraw API 和撤销集成仍需要按验收清单在宿主中验证。本次没有调用用户配置的外部模型服务，也没有将构建文件复制到其他库或发布版本。
