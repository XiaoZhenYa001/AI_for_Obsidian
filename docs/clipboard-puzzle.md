# 剪贴板拼图：功能与实现方案

> 文档状态：设计方案，尚未实现。  
> 适用环境：Windows 桌面工具箱。  
> 阅读对象：产品设计、交互设计和开发人员。  
> 更新日期：2026-10-08。  
> 文档目的：说明工具应提供的功能、便利性如何落地，以及嵌入工具箱时的集成方式、限制和开发范围。

## 1. 产品定位

剪贴板拼图将一次任务中连续复制的文字、链接和图片收集成素材，允许用户调整顺序、编辑内容，再以需要的形式一次性输出。

核心流程：

**开启收集 → 照常连续复制 → 集中整理 → 预览结果 → 复制或导出。**

它围绕“当前正在整理的一份内容”组织素材。剪贴板历史可以提供素材入口，拼图负责将素材组合成可使用的结果。

### 1.1 核心价值

- **减少窗口切换**：先在来源软件中收集，最后集中粘贴。
- **减少重复整理**：统一补充分隔符、编号、标题和输出格式。
- **保留工作上下文**：素材顺序、编辑结果和输出设置随草稿保存。
- **方便跨软件使用**：通过系统剪贴板和文件导出交付结果。
- **复用工具箱能力**：需要 OCR、文字清理或图片处理时，直接传递素材。

### 1.2 设计原则

1. 用户明确开启连续收集，启动工具箱时默认关闭。
2. 保留用户现有的 Ctrl+C 和 Ctrl+V 使用习惯。
3. 收集时不抢焦点、不逐条弹通知。
4. 一次复制对应一份逻辑素材，多种格式归属于同一份素材。
5. 默认按复制顺序输出，用户可以调整顺序和是否参与输出。
6. 编辑和转换保留原内容，支持撤销与恢复。
7. 预览真实反映输出结果，无法输出的内容必须明确提示。
8. 默认本地处理，临时草稿有明确的保留期限。
9. 工具箱页面和快捷浮窗共享任务与数据。

## 2. 典型使用场景

### 2.1 从多个网页整理资料

用户开启“资料整理”拼图，在不同网页中复制段落、链接和截图。收集完成后呼出面板，删除无关内容、调整顺序，输出为段落、列表或 Markdown。

涉及图片时，界面明确区分文字输出、图片输出和图文导出。

### 2.2 汇总聊天信息

用户连续复制多条聊天记录，补充说明后生成编号列表或事项清单。默认保留原文，由用户决定是否清理空行、调整措辞或删除内容。

### 2.3 汇集代码和报错

用户收集代码、错误信息和操作说明，按顺序组合成问题描述。代码缩进和原始换行应保留；格式化属于主动操作。

### 2.4 制作截图说明

用户收集多张截图，后续调用工具箱的图片拼接能力，生成纵向长图或网格图。需要识别文字时，对选中的图片调用 OCR。

图片拼接和 OCR 属于后续扩展，不作为第一版连续收集功能的前置条件。

## 3. 术语与任务状态

| 术语 | 含义 |
| --- | --- |
| 拼图／任务 | 一组围绕同一用途整理的素材及输出设置 |
| 素材／片段 | 一次复制或手动导入获得的逻辑内容 |
| 原始内容 | 收集时保存的受支持内容表示 |
| 编辑内容 | 用户编辑或工具转换后得到的内容 |
| 输出预览 | 按当前勾选状态、顺序和格式生成的结果 |
| 临时草稿 | 自动保存、具有保留期限的任务 |
| 已保存拼图 | 用户明确保存、长期保留的任务 |

### 3.1 收集状态

| 状态 | 行为 |
| --- | --- |
| 未开启 | 不自动读取复制内容；允许手动收下当前剪贴板 |
| 收集中 | 支持的剪贴板变化追加到当前任务 |
| 已暂停 | 保留现有素材，不自动追加新内容 |
| 服务异常 | 显示异常状态，停止展示“正在正常收集”的提示 |

同一时间只允许一个任务接收连续收集的内容。切换当前任务时，必须明确新的收集目标。

### 3.2 窗口与任务的关系

- 收起浮窗：隐藏界面，收集状态保持不变。
- 切换工具：当前草稿保持不变，收集状态仍可从托盘查看。
- 暂停收集：停止自动追加，素材仍可编辑和输出。
- 清空任务：仅清空该任务的素材，应提供撤销机会。
- 退出工具箱：停止服务并保存普通草稿。
- 重新启动：恢复草稿，连续收集保持关闭，等待用户主动开启。

工具箱若提供“关闭窗口后驻留托盘”，必须清楚区分关闭窗口与真正退出。

## 4. 功能要求

### 4.1 收集入口

提供三种入口：

1. **连续收集**：用户开始任务后，在其他软件中照常复制。
2. **收下当前内容**：读取当前剪贴板一次，不自动开启连续收集。
3. **面板内粘贴**：在工具面板中通过粘贴添加素材。

后续可增加拖入文件、从剪贴板历史选择素材等入口。

开启收集时，不自动导入开启之前的剪贴板内容；需要旧内容时，用户使用“收下当前内容”。

### 4.2 内容类型

| 类型 | 展示方式 | 保存与处理要求 |
| --- | --- | --- |
| 普通文字 | 摘要，展开查看完整内容 | 保留原始换行和空白，另存编辑结果 |
| 链接 | 地址及可用标题 | 不为生成预览默认访问网络 |
| 格式化文字 | 安全的简化预览 | 保存可用纯文本与受支持的 HTML 表示 |
| 图片 | 缩略图、尺寸和大小 | 保存原图，按需读取，支持单张复制或导出 |
| 不支持的专有格式 | 显示格式不支持 | 不创建成功状态的空卡片 |
| 文件引用 | 后续可展示文件名和路径 | 是否复制文件本体需另行设计，第一版不承诺支持 |

同一次复制中的纯文本和 HTML 属于同一份素材。不得因读取到多种表示而新增多张重复卡片。

HTML 预览需移除脚本和危险内容，默认不加载外部资源。保存内容表示不意味着可以完整还原来源软件的所有专有格式。

### 4.3 排序与取舍

- 素材按复制顺序追加。
- 默认勾选新素材，使其立即参与输出。
- 拖动卡片改变输出顺序。
- 支持键盘移动和多选删除。
- 取消勾选只排除输出，不删除素材。
- 删除、排序和编辑支持撤销。
- 长内容默认折叠，查看详情时展开。

第一版采用可排序列表。图片拼接和空间排版可以另设模式，避免基础文字整理依赖自由画布操作。

### 4.4 编辑与清理

提供片段编辑、补充说明、插入标题、恢复原文。

清理操作由用户主动触发，包括：

- 清理多余空行。
- 调整首尾空格。
- 批量添加前缀或后缀。
- 查找与替换。
- 选择性去重。

批量清理在应用前展示结果，并允许撤销。不得默认改变代码缩进、路径、数字格式或用户有意保留的重复内容。

### 4.5 输出方式

| 输出方式 | 用途 | 版本范围与限制 |
| --- | --- | --- |
| 段落合并 | 摘录与说明 | 第一版；支持换行、空行和自定义分隔符 |
| 项目列表 | 要点与事项 | 第一版；每个选中片段对应一个项目 |
| 编号列表 | 有序说明 | 第一版；自动生成编号 |
| Markdown 文字 | 笔记与技术文档 | 第一版；图片素材需要明确提示，不声称完整图文输出 |
| 单张图片复制／导出 | 使用已收集图片 | 第一版；针对选中的单张图片 |
| 图片拼接 | 多张截图展示 | 后续；纵向、横向、网格及间距设置 |
| Markdown 与图片资源包 | 可编辑图文资料 | 后续；同时导出 Markdown、图片和正确的相对引用 |
| 富文本图文 | 向文档软件粘贴 | 后续；按目标软件验证格式与图片兼容性 |

纯文本或文字 Markdown 输出遇到图片时，预览必须提示图片未包含，或明确展示用户选择的占位文字。

输出按钮使用明确名称，例如“复制文字”“复制图片”“导出 Markdown”。用户应能在执行前判断会得到什么结果。

默认成功复制组合结果后暂停连续收集，保留任务内容，并更新状态提示。用户可以设置继续收集。

第一版由用户回到目标软件自行粘贴。自动向其他窗口粘贴作为后续选项，需要单独处理目标窗口识别、焦点变化和失败恢复。

### 4.6 来源信息

可以记录复制时间、可获得的来源应用，以及剪贴板实际附带的来源网址。

- 网页来源网址不是每次复制都能取得。
- 前台应用信息只能作为辅助，不能保证它就是内容来源。
- 缺失信息显示“未知”，允许用户补充。
- 是否把来源写进输出，由用户决定。
- 不根据片段内容猜测并补写未经验证的网址或标题。

### 4.7 草稿与长期保存

普通模式下，素材、顺序、编辑内容和输出设置自动保存到本地。

建议临时草稿默认保留 24 小时，从最后一次内容变更计算；保留期限可配置。编辑中的当前任务不被后台突然清理。

已保存拼图由用户命名并明确长期保留。该能力可在后续版本增加。

另外提供“临时不落盘”模式：

- 素材仅保存在内存中。
- 退出后不恢复。
- 界面明确提示该模式不提供崩溃恢复。
- 不把内容写入日志、缓存或普通草稿文件。

## 5. 界面与便利性设计

### 5.1 完整页面

工具箱中的完整页面包含：

| 区域 | 内容 |
| --- | --- |
| 顶部状态区 | 任务名称、素材数量、开始／暂停、新建任务 |
| 素材列表 | 勾选、排序、摘要、图片缩略图、编辑与删除 |
| 输出预览 | 当前实际输出结果及未包含素材的提示 |
| 底部操作区 | 输出格式、分隔方式、复制或导出 |
| 更多操作 | 清理、来源、保留期限和后续扩展功能 |

列表就是组合顺序，避免要求用户把每条已收集素材再手动添加到第二个编辑区。

### 5.2 快捷浮窗

浮窗用于快速查看、简单排序和复制结果，可展开到完整页面。

- 通过全局快捷键直接呼出当前任务。
- Esc 收起，重新打开后恢复工作位置。
- 不因后台复制事件主动打开。
- 与完整页面共享状态，不创建另一份独立任务。
- 需要编辑时获得焦点；只展示收集数量的状态条不抢焦点。

### 5.3 快捷键

建议提供可配置命令：

1. 呼出／收起面板。
2. 开始／暂停连续收集。
3. 收下当前剪贴板，可选配置。

不拦截或替换系统的 Ctrl+C 和 Ctrl+V。

快捷键注册失败时显示冲突，并允许修改。默认组合需在实际宿主工具箱及常见软件中检查后确定。

### 5.4 低打扰反馈

- 收集成功：更新数量和列表，不逐条弹系统通知。
- 收集异常：显示明确状态，必要时给一次提示。
- 复制结果成功：提示当前输出类型与收集状态。
- 容量达到限制：停止追加并提示处理方式，不静默丢弃内容。

### 5.5 便利性验收

便利性通过实际任务验证：

- 收集十条资料时，不需要每次打开面板。
- 用户可通过一次快捷操作直接到达当前任务。
- 简单文本任务可直接输出，排序和编辑属于按需操作。
- 组合结果只需一次复制，之后在目标软件粘贴。
- 关闭面板、切换工具后，无需重新建立任务。
- 常用操作可以使用键盘完成。

性能目标应在确定宿主框架和测试机器后制定，并记录实测结果。本方案不把未经测试的响应时间或节省比例作为既有能力。

## 6. Windows 实现要点

### 6.1 事件驱动收集

使用 Windows 剪贴板格式监听机制：

- 注册 AddClipboardFormatListener。
- 接收 WM_CLIPBOARDUPDATE。
- 收集开启时读取受支持格式并生成素材。
- 服务停止时移除监听并释放资源。

系统监听由工具箱共用服务负责。避免多个工具分别监听和保存同一份内容。

### 6.2 读取与异常处理

- 剪贴板暂时无法读取时，采用有上限的短暂重试。
- 在读取前后检查变化标识，避免把不同复制操作的表示拼成同一份素材。
- 读取完成后尽快释放系统资源。
- 图片处理、预览生成和磁盘写入放到异步任务中。
- 按捕获顺序提交素材，避免图片处理较慢导致顺序改变。
- 对不支持格式、超限内容和持续读取失败显示明确状态。
- 快速连续复制需要实测；监听通知不等于可以保证取得每个已被后续复制覆盖的中间状态。

工具应保存自己实际取得的数据，不宣称可以恢复系统剪贴板在工具启动前的所有内容。

### 6.3 重复事件与主动重复

需要区分两类情况：

- 同一次剪贴板写入产生的重复处理：应抑制。
- 用户有意再次复制相同内容：允许保留。

变化标识、内容指纹和短时间窗口可以帮助识别重复处理，但不应默认在整个任务中按内容全局去重。

全局内容去重作为显式操作，预览后应用。

### 6.4 自身输出防回流

工具写入最终结果时，记录本次写入标识或使用适合宿主的自定义格式标记。

收集服务识别自身输出后，不把组合结果自动追加为新素材。

不得通过“无条件忽略下一次剪贴板事件”处理，否则可能忽略用户随后从其他软件复制的真实内容。

### 6.5 格式兼容

- 素材内部保存受支持的原始表示与用于编辑的规范化内容。
- 输出端针对目标格式生成内容。
- 富文本输出可以同时提供纯文本后备表示。
- 专有格式和图文粘贴需按目标软件验证。
- 当前工具箱若已有剪贴板适配层，优先复用并补足能力。

具体接口随宿主框架选择；本方案不预设必须更换现有技术栈。

## 7. 工具箱集成架构

| 模块 | 职责 | 生命周期 |
| --- | --- | --- |
| 剪贴板适配层 | 监听、读取、格式识别、写入 | 工具箱共用基础服务 |
| 收集控制器 | 收集开关、当前任务、过滤、重复处理和输出回流识别 | 与页面是否打开无关 |
| 任务仓库 | 素材、顺序、编辑、草稿保存与清理 | 普通模式本地持久化 |
| 组合与导出模块 | 根据输出规则生成预览和最终结果 | 按用户操作执行 |
| 界面层 | 完整页面、快捷浮窗和状态提示 | 按需展示 |
| 工具调用层 | OCR、文字清理、图片处理等协作 | 按需加载和调用 |

页面关闭后，不应丢失任务。后台服务启动时，也不应加载所有图片编辑器和 OCR 等重型模块。

### 7.1 与剪贴板历史协作

如果工具箱已有剪贴板历史：

- 共用剪贴板监听与格式识别。
- 历史记录与任务素材使用各自明确的保留策略。
- 提供“选中记录加入当前拼图”。
- 不因开启拼图自动开启工具箱的全量长期历史记录。
- 不因删除拼图素材意外删除其他工具的历史记录。

### 7.2 与其他工具协作

| 当前素材 | 可调用能力 | 结果返回方式 |
| --- | --- | --- |
| 图片 | OCR | 文字作为新片段，保留来源图片 |
| 文字 | 清理、替换 | 预览后更新编辑内容，保留原文 |
| 代码 | 格式化 | 预览后更新编辑内容，可撤销 |
| 多张图片 | 图片拼接 | 成图加入当前任务或直接导出 |

工具之间直接传递选中素材及任务上下文，避免要求用户重复复制和粘贴。

转换结果应关联来源素材。失败时保留原内容，提示失败原因和重试入口。

## 8. 数据组织建议

数据结构是概念设计，字段名称和存储技术由实现时确定。

### 8.1 任务

| 字段 | 用途 |
| --- | --- |
| 唯一标识 | 区分不同拼图 |
| 名称 | 用户识别当前任务 |
| 素材顺序 | 决定输出顺序 |
| 输出设置 | 格式、分隔符、来源开关等 |
| 创建与更新时间 | 恢复、排序和到期清理 |
| 保存状态 | 临时草稿或长期保存 |
| 存储模式 | 本地草稿或仅内存 |

### 8.2 素材

| 字段 | 用途 |
| --- | --- |
| 唯一标识与所属任务 | 定位素材 |
| 类型与可用表示 | 文字、HTML、图片等 |
| 原始内容或资源引用 | 恢复原文与输出 |
| 编辑内容 | 保存用户修改 |
| 是否参与输出 | 保留素材但排除结果 |
| 捕获顺序与时间 | 保持顺序 |
| 来源信息 | 可选，允许未知 |
| 内容指纹 | 辅助识别重复 |
| 来源素材关系 | 追踪 OCR、清理等转换结果 |

图片等较大资源适合独立保存，任务数据保存引用。清理资源前检查其他任务是否仍在引用，避免误删共享素材。

## 9. 默认行为与缺点控制

| 问题 | 建议默认行为 |
| --- | --- |
| 无关复制混入 | 连续收集默认关闭，用户明确开始和暂停 |
| 收集状态容易被忘记 | 托盘持续展示收集状态和数量 |
| 隐私内容长期留存 | 本地处理、临时草稿到期清理、应用排除、仅内存模式 |
| 内容清理破坏原文 | 不自动改写，保留原文，支持预览和撤销 |
| 重复复制堆积 | 抑制重复处理；全局去重由用户主动执行 |
| 图片资源过大 | 缩略图展示、原图按需读取、容量限制和清理入口 |
| 输出格式不兼容 | 真实预览、明确格式名称、提供替代输出方式 |
| 服务异常却显示正常 | 异常状态与正常收集状态明确区分 |
| 快捷入口和完整页面不同步 | 共用任务仓库和收集控制器 |
| 功能过多增加操作负担 | 基础操作常显，清理和扩展放入更多菜单 |

### 9.1 隐私与内容处理

- 默认不上传、同步或发送素材给外部服务。
- 日志记录状态和错误，不记录剪贴板正文或图片。
- 提供应用排除，但来源识别失败时不能声称一定能过滤。
- 敏感内容识别只能辅助提醒，不能保证识别所有密码或验证码。
- 对明确表示不应进入历史记录的剪贴板标记，设计适当的跳过策略。
- 本工具仅本地处理，不代表系统或其他剪贴板软件不会另行记录内容。
- 清理本地草稿不自动清空系统剪贴板；两者分别操作。

### 9.2 容量与到期清理

素材数量、单条大小、图片尺寸和任务总容量应设置可配置上限，初始值在实际测试后确定。

达到限制时明确说明：

- 哪条内容没有加入。
- 是数量、大小还是格式问题。
- 如何清理、导出或调整限制。

不得静默截断文字或压缩原图后仍声称保存了完整原内容。

## 10. 开发范围

### 10.1 第一版：完成核心流程

- 手动收下、面板粘贴、连续收集与暂停。
- 普通文字、链接、图片收集。
- 图片缩略图、单张复制与导出。
- 素材排序、勾选、删除、轻量编辑。
- 核心操作撤销、恢复原文。
- 段落、项目列表、编号列表、文字 Markdown 输出。
- 图片未包含等输出提示。
- 快捷浮窗与工具箱页面共享草稿。
- 普通草稿自动保存与恢复，重启后不自动收集。
- 收集状态提示、容量处理和自身输出防回流。
- 本地保留期限、一键清理和基本隐私设置。

### 10.2 第二阶段：发挥工具箱协作优势

- 多图拼接与排版。
- OCR 和文字清理等工具调用。
- 长期保存拼图和常用模板。
- 从剪贴板历史选择素材。
- 来源信息增强与来源输出。
- Markdown 图文资源包。

### 10.3 后续按需求增加

- 经目标软件验证的富文本图文输出。
- 结构化表格与 TSV 等输出。
- 自动粘贴到目标窗口。
- 多任务搜索和分类。
- 跨设备同步或 AI 整理。

同步、AI 和网页内容抓取涉及额外数据流，需单独设计启用方式和内容发送范围，不作为基础收集的依赖。

## 11. 验收场景

以下是计划验收项，不代表已经实现或测试通过。

| 场景 | 预期结果 |
| --- | --- |
| 从多个软件连续复制十条文字 | 素材按捕获顺序追加，收集过程不抢焦点 |
| 一次复制同时含文字和 HTML | 仅产生一张逻辑素材卡片 |
| 有意重复复制相同内容 | 不被全局去重机制悄悄删除 |
| 快速连续复制 | 在明确测试条件下验证捕获情况，记录遗漏与限制 |
| 收集文字和图片 | 类型与预览正确，图片处理不打乱顺序 |
| 文字模式中勾选图片 | 明确提示图片是否包含，预览与输出一致 |
| 修改后恢复原文 | 原始内容可恢复，编辑可撤销 |
| 收起浮窗并切换其他工具 | 当前草稿、顺序和输出设置保持不变 |
| 同时使用浮窗和完整页面 | 修改同步，不出现两个收集目标 |
| 暂停后继续复制 | 当前任务不追加，用户仍可手动收下 |
| 复制组合结果 | 成功写入剪贴板，结果不自动回流成新素材 |
| 工具箱重启 | 普通草稿恢复，连续收集保持关闭 |
| 使用仅内存模式 | 退出后不恢复内容，不留下普通草稿文件 |
| 剪贴板读取失败或格式不支持 | 显示真实状态，不生成成功状态的空卡片 |
| 内容超过容量限制 | 明确提示未加入原因，不静默截断 |
| 快捷键发生冲突 | 提示注册失败，允许修改 |
| 调用其他工具失败 | 原素材不丢失，可重试或取消 |
| 在目标软件粘贴结果 | 按声明的格式兼容范围正确使用 |

## 12. 实现前需要确定的参数

- 宿主工具箱框架及已有的剪贴板服务。
- 工具箱关闭窗口后的驻留行为。
- 快捷键默认组合及冲突处理。
- 首批兼容测试的目标软件。
- 素材数量、单条大小、图片尺寸和总容量限制。
- 草稿保留期限的最终默认值。
- 应用排除与仅内存模式的具体入口。
- 长期保存、图片拼接和其他工具协作的迭代顺序。

这些参数可以在进入开发阶段时确定，不影响本方案的核心流程。
